              Setup & Help

              First-time setup · ongoing guidance · troubleshooting

              Welcome to Command Center

              This page walks you through everything: opening the app, getting it on your phone, daily use, and troubleshooting. The blue ? button (bottom-right) is always available for quick "How do I..?" questions on any page.

              3 sections below
              ~15 min full setup
              1First-Time Setup · Do This Once
              Step 1 · Open the dashboard on your office computer
              1. Save the Five_Dive_Command_Center.html file to your computer (anywhere — Desktop is fine)
              2. Double-click to open in your web browser (Chrome recommended)
              3. The lock screen appears immediately
              Pro tip Right-click the file → "Open with" → pick Chrome to always use it. Then bookmark or pin the tab.
              Step 2 · Jerrod claims the master account FIRST

              Important: whoever signs in as "Jerrod Sutherland" first becomes the master. Do this before sharing the file with anyone.

              1. Pick "Jerrod Sutherland" from the dropdown
              2. Click Continue → it asks you to set a password (6+ chars)
              3. Pick a security question and answer it (case-insensitive)
              4. The dashboard generates a 4-word recovery phrase (e.g. cedar-thunder-violet-jasmine)
              5. SAVE THIS PHRASE NOW. Password manager, email it to yourself, write it down. You only see it once.
              6. Click "I've saved it" → you're signed in
              Critical If you lose both your password AND your security answer AND your recovery phrase, you cannot get back in. The phrase is your last-resort key.
              Step 3 · Take your first backup right now
              1. You should now see the Dashboard page
              2. Top-right, click "Backup"
              3. A JSON file downloads — name it something like five-dive-day-1-backup.json
              4. Email it to your personal Gmail OR drop into Google Drive / OneDrive / Dropbox
              Why now This is your safety net. If anything goes sideways during setup, you can Restore from this and you're back. Habit: backup every Sunday.
              Step 4 · Host the dashboard online (recommended for phone use)

              Right now you're running the dashboard from a local file. For phones — especially iPhone — hosting online is much more reliable. Pick one of these free options:

              Option A · Netlify Drop (easiest)
              1. Rename the file to index.html
              2. Go to app.netlify.com/drop
              3. Drag the file onto the page
              4. You get a URL like random-words-12345.netlify.app
              5. Sign up free to claim it; set a custom name like fivedive-command.netlify.app
              6. To update later: drag a new file onto the same site
              Option B · GitHub Pages (most professional)
              1. Sign up at github.com/signup (use work email)
              2. Top-right + → "New repository"
              3. Name it fivedive-command, set Public, check "Add README", create
              4. Click "Add file" → "Upload files" → drag the HTML file in → rename it to index.html → commit
              5. Repo settings → Pages → Source: "main" branch → Save
              6. Wait 1-2 min — your URL is https://YOURNAME.github.io/fivedive-command
              About privacy The URL is public but the lock screen protects all data. Anyone who finds the URL just sees a login screen.
              Try Netlify Try GitHub

              Troubleshooting
              "I lost data after updating to a new version"

              Starting with this version, the dashboard auto-migrates data forward. If you backup your data file (Settings → Backup) and Restore it, you're never going to lose anything.

              "I forgot my password"

              On the sign-in screen, tap "Forgot password?" — answer your security question OR paste your recovery phrase, set a new password. If both lost, Jerrod can reset you from Settings → Master Controls.

              "My phone keeps losing data after a few days"

              iPhone Safari clears local storage if you don't open the app for ~7 days. Fix: host the dashboard online (Section 1 → Step 4). Once it's a real website, iPhone gives it full storage permissions and data persists indefinitely.

              "The mic doesn't work / picks up wrong words"

              Browser needs mic permission (grant on first use). Loud bars = poor accuracy — use typed input below the mic button instead. Mic auto-stops after a pause; tap again to continue.

              "Someone's edits aren't showing up on my device"

              Each device has its own copy until someone Backups and shares the JSON for Restore. For real-time sync, the dashboard needs to move to a hosted backend (Path A) — separate project.

              "How do I add a new manager who isn't in the dropdown?"

              Only Jerrod can do this. Sign in as Jerrod → Settings → "Manager / Team Management" → fill in name/role → click + Add. The new manager then appears in the sign-in dropdown.
